# Dashboard Gerencial - Coordenação MR10 (Dicere Telecom)

Painel web interativo desenvolvido em **Python** com **Streamlit** para o monitoramento diário do desempenho comercial das 7 lojas da coordenação **MR10**:
1. **Moinhos** (Gerente: Cleonice)
2. **Sapucaia Matriz** (Gerente: Cassia)
3. **Sapucaia Calçadão** (Gerente: Barbara)
4. **Esteio** (Gerente: Emily)
5. **Igrejinha** (Gerente: Carolina)
6. **Parobé** (Gerente: Nagai)
7. **Taquara** (Gerente: Eduarda)

## 🚀 Funcionalidades
* **Visão Consolidada e por Loja:** Alternância dinâmica entre a visão geral da coordenação e o detalhamento individual de cada unidade.
* **KPIs e Pilares Comerciais:** Acompanhamento de Faturamento, Metas, Projeções, Vendas de TV (Claro TV+), Vírtua, Aparelhos, Controle e Seguros.
* **Gráficos Dinâmicos:** Comparativos visuais de atingimento e curvas de performance.

## 🛠️ Tecnologias Utilizadas
* Python
* Streamlit
* Pandas / NumPy
* Openpyxl
